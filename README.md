# Cloud Computing Lab

## Experiment 2: Implementation of Cloud Service Models

This repository contains the implementation of the three major cloud service models:

* **IaaS (Infrastructure as a Service)**: Apache web server hosted on an Ubuntu virtual machine.
* **PaaS (Platform as a Service)**: Python Flask web application deployed using Render.
* **SaaS (Software as a Service)**: Google Docs used for creating and sharing an online document.

## Technologies Used

* Ubuntu
* VirtualBox
* Apache2
* Python
* Flask
* GitHub
* Render
* Google Docs

## IaaS

An Ubuntu virtual machine was used to install and run the Apache2 web server.

The Apache server was accessed using:

```text
http://localhost
```

and the virtual machine IP address:

```text
http://10.0.2.15
```

The Apache2 Ubuntu Default Page was successfully displayed.

## PaaS

A Python Flask application was created with the following output:

```text
Hello from PaaS
```

The application was deployed using Render.

## SaaS

Google Docs was used to create and share an online document. The document can be accessed through a web browser and edited collaboratively by multiple users.

## Result

The three cloud service models were successfully demonstrated:

| Service Model | Technology Used  |
| ------------- | ---------------- |
| IaaS          | Ubuntu + Apache2 |
| PaaS          | Flask + Render   |
| SaaS          | Google Docs      |
